## Project Overview

The Bodyweight Gym Online is a fully static site (hosted on GitHub Pages at thebodyweightgym.org) offering bodyweight workout videos as YouTube embeds, with filtering, search, favourites, a blog and a PWA shell. There is no backend; see `README.md` for deploy steps.

## Architecture

- **public/**: the deployed site root. Pages: `index.html`, `video.html` (`/video?id=`), `blog/index.html`, `blog/post.html` (`/blog/post?slug=`), `books/` (`/books`, `/books/handstand`, `/books/ring-muscle-up`), `ebook.html` (redirect to `/books`), `404.html`.
- **public/data/videos.json**: hand-edited video database (fields incl. `youtubeId`, `startTime`). `categories.json`, `instructors.json`, `blogs.json` are generated by `npm run build` (`scripts/build-data.js`).
- **scripts/blog-meta.json**: which blog posts are published, their order and card metadata.
- **public/js/data.js**: shared helpers (`window.BWG`): JSON loading, favourites in `localStorage`, stats. **public/js/modern-app.js**: home page logic (filters, search, cards).
- Videos play in a `youtube-nocookie.com` iframe using `youtubeId` and `startTime`; blog markdown is fetched and rendered client-side with `marked`.
- **Books:** `public/books/*.html` (static pages with OG tags and Book JSON-LD), `public/css/books.css`, `public/js/books.js`. Amazon URLs and the signup option live only in `public/js/books-config.js`; a `TODO_...` value renders a disabled "coming soon" button, never a link. No book text, PDFs or EPUBs in the repo (KDP terms). Copy rules for site text: plain voice, no em dashes, no hype words, no invented reviews or results.
- Do not add `/api/*` calls; everything is fetched from static files.

## Common Commands

```bash
npm run build   # regenerate public/data/*.json
npm start       # preview with npx serve public
npm run images                      # book covers/photos (needs npm install for sharp)
npm run thumbnails                  # FFmpeg thumbnails
node analyze-video-start-times.js   # detect start times
node update-video-database.js       # merge start times into videos.json
```

## Video Data

Each entry in `public/data/videos.json`:
```javascript
{
  id, title, instructor, duration, level, category, equipment,
  description, thumbnail, filename, youtubeId, views, rating,
  startTime, startTimeFormatted
}
```
`youtubeId` is the 11-character YouTube ID (`"TODO"` until known). `views` is refreshed from YouTube by `npm run build` when `YOUTUBE_API_KEY` is set (otherwise the stored count is kept); the home page can sort by `rating` or `views`. `startTime` (seconds) is passed to the embed to skip intros; it comes from `analyze-video-start-times.js` (FFmpeg scene/audio analysis, needs local video files) and is merged in by `update-video-database.js`.

## Adding New Videos
1. Add an entry to `public/data/videos.json` with the `youtubeId`.
2. Put a thumbnail in `public/images/thumbnails/` (`npm run thumbnails` if you have the file locally).
3. `npm run build`, then commit `public/data/`.
